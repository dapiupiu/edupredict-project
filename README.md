# 🎓 EduPredict AI

## Overview

EduPredict AI merupakan proyek Data Science end-to-end yang bertujuan membantu institusi pendidikan mengidentifikasi siswa yang berisiko mengalami penurunan performa akademik sejak dini. Proyek ini mengintegrasikan proses pengolahan data, analisis eksploratif, machine learning, dashboard interaktif, serta A/B Testing untuk menghasilkan insight yang mendukung pengambilan keputusan berbasis data.

## Business Problem

Institusi pendidikan sering menghadapi kesulitan dalam mendeteksi siswa yang berpotensi mengalami penurunan prestasi akademik. Tanpa analisis yang sistematis, intervensi yang diberikan cenderung terlambat sehingga berdampak pada hasil belajar siswa.

## Solution

EduPredict AI dikembangkan untuk:

* Mengidentifikasi faktor-faktor yang memengaruhi performa akademik siswa.
* Menghasilkan insight melalui Exploratory Data Analysis (EDA).
* Memprediksi tingkat risiko akademik siswa menggunakan machine learning.
* Menyajikan hasil analisis dalam dashboard interaktif.
* Mendukung pengambilan keputusan berbasis data bagi stakeholder pendidikan.

## Project Scope

### Problem Discovery

Mengumpulkan dan menganalisis berbagai permasalahan yang berkaitan dengan performa akademik siswa, kemudian menentukan solusi utama yang akan dikembangkan dalam proyek.

### Data Wrangling

Melakukan proses pengumpulan, evaluasi, dan pembersihan data agar siap digunakan untuk analisis dan pemodelan.

### Business Understanding

Mendefinisikan pertanyaan bisnis yang dapat diukur dan dijawab menggunakan data.

### Exploratory Data Analysis (EDA)

Mengeksplorasi data untuk menemukan pola, hubungan antar variabel, serta insight yang relevan dengan permasalahan bisnis.

### Data Visualization

Menyajikan hasil analisis dalam bentuk visualisasi yang mudah dipahami dan digunakan sebagai dasar pengambilan keputusan.

### Feature Engineering

Membuat dan memilih fitur yang lebih informatif untuk meningkatkan performa model machine learning.

### Dashboard Development

Mengembangkan dashboard interaktif menggunakan Streamlit untuk menampilkan insight, hasil analisis, dan prediksi risiko akademik siswa.

### Deployment

Melakukan deployment dashboard ke Streamlit Cloud agar dapat diakses secara publik.

### A/B Testing

Mengimplementasikan pengujian statistik menggunakan Python untuk mengevaluasi efektivitas solusi atau rekomendasi yang diberikan.

### Technical Report

Menyusun laporan teknis komprehensif yang mendokumentasikan seluruh tahapan proyek mulai dari Problem Discovery hingga hasil akhir.
